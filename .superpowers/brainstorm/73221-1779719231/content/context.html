Chat History Full-Text Search — Current Architecture

What we have today and what we need to add

Current Chat Message Flow

Frontend (ChatPanel.vue)

On mount: GetMessages(10) → load first page

Lazy load: IntersectionObserver → GetMessagesBeforeID(oldestID, 10)

Rendering: messages.value (flat array), no search/filter

DB schema: messages table → id, role, content, created_at, images, files, thinking_content

Backend (app_chat.go + short.go)

GetMessages(limit) — most recent N

GetMessagesBeforeID(beforeID, limit) — cursor pagination

No search method — no FTS index

SQLite: simple B-tree on messages.id

The Problem

ChatPanel has infinite-scroll lazy loading (only ~10 messages in memory at a time for large histories).

Full-text search needs to either:

  1. Search server-side (SQLite FTS) and return matching messages — ignoring the lazy-load mechanism
  2. Search client-side after loading all messages — conflicts with lazy loading
  3. Hybrid — search server-side, but display results with lazy-load-aware navigation
