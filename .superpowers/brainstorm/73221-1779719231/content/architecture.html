Implementation Approach

Backend FTS5 + Frontend Search State Machine

Backend Changes

New DB: FTS5 Virtual Table

CREATE VIRTUAL TABLE messages_fts USING fts5(content, content=messages, content_rowid=id)

FTS5 content-sync mode — auto stays in sync with messages table, no triggers needed

Search query: SELECT rowid FROM messages_fts WHERE messages_fts MATCH ? → join back to messages

New Wails Bindings

SearchMessages(query) → []Message (全量)

GetMessagesFromNewestToID(targetID, pageSize) → []Message (跳转用)

Frontend State Machine

Normal

messages.value — normal lazy-load list

IntersectionObserver active

🔍 click → enter Search

Searching

Save snapshot: {messages, oldestLoadedID, allLoaded, scrollTop}

IntersectionObserver → disabled

messages.value = filtered results with highlights

Clear query / ✕ → restore Normal

Click result → enter Jump

Jump

Exit search, load from newest → target page

Scroll to target message, flash highlight

Resume IntersectionObserver

→ Normal
